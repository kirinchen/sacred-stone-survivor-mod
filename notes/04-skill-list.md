# 04 原作招式清單 + 分組(做技能樹用)

> 2026-11-20(Kirin:「原版的技能是平鋪的沒有什麼技能 tree,LIST 所有的技能然後把它很像的 group 起來,我們自己來做技能 tree」)。
> 來源:`game/sss_mod.log` 裡 v1 開發時的 `moves` 傾印(招式表 `*(0x4c320c)+4`,V2.85),**沒重開遊戲**。只列名字與幾個數值欄,不含原作資料檔。

## 總覽

- 招式 id 1–83,有效 **78 招**(含 2 個 `Dummy` 佔位:66、70)。6 / 8 / 12 / 21 / 37 是 v1 掃表時塞進去的垃圾,不算。
- 原作是**平鋪**的:每招一筆,沒有前置 / 分支 / 等級欄位。誰會哪招存在角色資料,這份傾印沒有 → **「誰的招」下面是照名字推的,沒驗證**。
- 名字帶「人名-」前綴的(魔魁、劍上卿、非善類首領、鬼眼鼠、劍無言)是**頭目專用**;內力 16 的多半也是敵方招(不必顧內力)。

### 欄位(意義大多還沒驗)

| 欄 | 值 | 推測 |
|---|---|---|
| 屬性碼 | 1 / 2 / 4 / 8 / 16(位元)| 五種屬性(很可能是五行);哪個值是哪行**未驗** |
| f20 | 1 / 2 / 3 / 4 / 6 | 可能是招式類型 / 範圍形狀,未驗 |
| 威力 | 0–200 | `+0x24`;絕招傷害 = 威力 ×(100 − 抗性)%,跟攻擊力無關 |
| 內力 | 0–60 | `+0x28`,放招消耗 |
| f2c | 1 / 2 | 可能是單體 / 範圍,未驗 |
