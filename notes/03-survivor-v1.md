## 結論

**可行,而且都是呼叫 / 改原作自己的東西,不是模擬按鍵。**

| 要試的 | 結果 | 怎麼做的 |
|---|---|---|
| 自動普攻 | ✅ | 直接呼叫原作「攻擊目標」`0x447230`(原作 AI 自己也用這支) |
| 定時自動放絕招 | ✅ | 直接呼叫原作「放第 N 招」`0x446e80`,對「周圍最密」的敵人放,會的招輪流用 |
| 擊殺 → 經驗 → 升級暫停選 3 選 1 | ✅ | 原作暫停旗標 `app+0x12` + overlay 選單,數字鍵 1–3 |
| 升級改原作數值(攻 / 防 / 命 / 速度) | ✅ | 改數值區塊 `obj+0x1a4`,呼叫原作重算 `0x408680` |
| 升級學新絕招 | ✅ | 原作 `0x407ee0(stat, moveId)`;招式表 83 招都列得出來 |
| 升級換武器 | ✅ 數值(log:換凌雲劍後有效攻 23 → 53);外觀沒對照 | 寫裝備格 `stat+0x84` + 重算 |
| 召喚助戰 | ⚠️ 生得出來,**有沒有真的幫打沒確認** | 生一隻陣營 1(友方)的刀手 |
| 任何地圖都能開打 | ✅ 意外收穫 | 關卡旗標 `stage+0x79c` bit 2 打開就是戰鬥地圖 |
| Q 換戰友接招 | ❌ 沒實測 | 這個存檔只有青陽子一位戰友;而且逆向發現 Q 不是「換人操作」(見下) |
| 模擬熱鍵(F1–F4 / Shift+點) | 沒用上 | 原作是輪詢掃描碼表,不是訊息直送;直接呼叫函式比較乾淨 |

## 怎麼玩

1. `tools/load.sh`(重建 → 開遊戲 → 讀自動存檔,約 25 秒)或自己開遊戲走到任一張地圖
2. **F9** 開始 / 提前結束 / 收起結算畫面
3. 主角自動打:不按滑鼠時普攻最近的敵人,每 4 秒放一次絕招。**按住左鍵可以自己走位**(按著時不搶控制)
4. 每升一級遊戲停住,**按 1 / 2 / 3** 選一個

## 規則(v1)

| 項目 | 值 |
|---|---|
| 經驗 | 1 擊殺 = 1 經驗(隊友殺的也算);升到 Lv N+1 要 `4 + 3N`(第一次 5) |
| 開場加成 | 主角命上限 ×3(原作 Lv1 素還真 122 命,被圍 5 秒就死)、每秒回 命 2 / 內 3 |
| 波次 | 第 w 波 `4 + 2w` 隻;間隔 8 秒遞減到 4 秒;場上上限 80 |
| 怪物強度 | 攻 = 原作的 `25% + 4%×波`、命 = `30% + 4%×波`,上限 120% |
| 怪物種類 | 蝙蝠 → 蜘蛛(2 波)→ 黃刀手(3)→ 蟾蜍(5)→ 黃弓手(6)→ 強化版刀手 / 大蜘蛛(8、9、11) |
| 追擊 | 沿用 v0 推力(每 50 ms 推 2 px);每隻停的距離不同(34–94 px),不會全疊在一點 |
| 拴繩 | 只追離「開始位置」230 px 內的敵人(不然會追進出口換地圖) |
| 結束 | 主角命歸零 / 換地圖 / F9;結束時把主角數值、武器、招式威力、地圖旗標還原(學會的招不會忘) |

升級選項池(每次隨機 3 個,到上限的不出):

| 選項 | 改了什麼 |
|---|---|
| 攻擊 +5 | `stat+0x60`(基礎攻)→ 重算 |
| 防禦 +4 | `stat+0x64` → 重算 |
| 命上限 +25% 並回滿 | `stat+0x54 / +0x50` |
| 命、內全滿,每秒回復 +2 | 模組自己的回復量 |
| 移動速度 +15% | `obj+0xf8` |
| 絕招間隔 −20% | 模組的放招計時(4 秒起,最低 0.8 秒) |
| 絕招威力 +30% | 招式表 `moveDef+0x24`(結束還原)。**寫進去了,傷害數字有沒有變沒量** |
| 學新絕招 | 玄子神功 → 旋空斬 → 怒火燒盡九重天 → 天地根 → 般若懺 → 九州生氣恃風雷 → 君子風 |
| 換武器 | 鋼劍(攻 8)→ 明月劍 18 → 凌雲劍 30 → 烈陽劍 45 → 擎天神劍 62 → 寰宇神劍 68 |
| 召喚一名刀手助戰 | 生陣營 1 的黃刀手 |

可調指令(`game/sss_cmd.txt`):`auto 0|1`、`castms N`、`leash N`、`super 0|1`(霸體)、`pick N`、`learn 招式id`、`moves A B` / `items A B`(列表)、`goto X Y`(原作走到)、`row T0 STEP N CHAR`(排一排圖像)、`peek` / `poke`。

## 逆向到的東西(V2.85)

全域:`app = *0x4c31ec`(視窗物件)、`gs = *0x4c3214`(遊戲狀態;`+8` 主角、`+0xc` 戰友)、`mgr = *0x4c31f0`。

| 位址 | 是什麼 |
|---|---|
| `0x447230` thiscall(obj, targetId, wx, wy, hasTarget) | 普攻;`targetId` = 目標的 `obj+0xc` |
| `0x446e80` thiscall(obj, moveIdx, targetId, wx, wy) | 放「會的第 moveIdx 招」;內力、冷卻、忙碌不過就默默不放 |
| `0x446cf0` thiscall(obj, flag) | 能不能行動:`obj+0x188 != 0` 就不行 |
| `0x445a80` thiscall(obj, wx, wy) | 走到 |
| `0x407ee0` thiscall(stat, moveId) | 學絕招(`0x407f70` 忘掉) |
| `0x408680` thiscall(stat) | 重算有效數值(基礎 + 四格裝備) |
| `0x407b60` thiscall(stat, itemId) | 物品進背包(不是學招) |
| `0x4582b0` thiscall(gs) | Q:**輪替上場的戰友**(名單 `gs+0x44`),主角不變 |
| `app+0x12`(byte)、`0x476490()` | 暫停旗標(邏輯和畫面都停)、恢復時重設計時 |
| `stage+0x79c` bit 2 | 這張地圖能不能戰鬥;`+0x790 / +0x794` 地圖寬高 |
| `0x4c78a0 / 0x4c78e0` | 鍵盤掃描碼位元表(按住 / 剛按下),HUD `0x4165b0` 每幀輪詢 |
| `0x4c790c` | 滑鼠鍵(1 左 2 右) |

數值區塊 `stat = obj+0x1a4`:

| 偏移 | 意義 |
|---|---|
| `+0x28` / `+0x2c[]` | 選中的絕招格 / 各格對應會的第幾招 |
| `+0x3c` | 絕招傷害加成 %(**每次放招被原作重設**,不能拿來做升級) |
| `+0x40 / +0x44 / +0x48` | 等級 / 經驗(怪 = 擊殺給的經驗)/ 下一級門檻 |
| `+0x50 / +0x54`、`+0x58 / +0x5c` | 命、內(現 / 上限,上限 999) |
| `+0x60 → +0x138` | 攻(基礎 → 有效;基礎上限 255) |
| `+0x64 → +0x13c` | 防 |
| `+0x68 → +0x140`、`+0x6c → +0x144` | 絕招抗性 %、普攻命中 % |
| `+0x84..+0x90` | 四格裝備(`+0x84` 武器) |
| `+0xa0 / +0xa4` | 會的絕招 id 陣列(begin / end) |

物件:`+0xc` id、`+0xf8` 移動速度(16.16)、`+0x134` 目前指令(5 = 攻擊)、`+0x13c` 攻擊目標、`+0x188` 動作 / 硬直剩餘。

表:招式 `*(0x4c320c)+4`、物品 `*(0x4c3208)` 都是 VC6 `std::map`(節點 `+0xc` key、`+0x10` 值)。招式 `+0` 名字、`+0x24` 威力、`+0x28` 內力;物品 `+0` 旗標(`0x80000001` 武器)、`+4` 名字、`+0xc4` 攻、`+0xc8` 防。
實測 id:絕招 1–83(素還真初始只會 2 龍氣劍)、武器 101–137。怪物圖像 type 2071 蝙蝠、2072 蜘蛛、2073 黃刀手、2074 黃弓手、2075 蟾蜍、2077 紅袍刀手(琉璃仙洞用的)…到 2115。

傷害公式(靜態讀到,沒逐項驗):普攻 = 攻 − 防 ±20%,屬性相剋 ×1.5,最少 1;絕招 = 招式威力 ×(100 − 抗性)%,**跟攻擊力無關**。

## 踩到的坑

1. **查表函式會寫入**:`0x427e30`(招式)/ `0x427e10`(物品)是 `map::operator[]`,查不存在的 id 會插入一筆垃圾。拿它掃 1–20000 等於往表裡塞了兩萬筆 → 改成自己走紅黑樹(`map_find`)。
2. **暫停旗標連畫面一起停**:選單還沒畫出來遊戲就凍住,按鍵也被擋。改成「選單畫出一幀之後才設旗標」,畫面就停在有選單的那一幀;暫停中截圖改讀上一幀的 back buffer。
3. **自動追怪會追出地圖**:追進洞口 → 換地圖 → 倖存者結束,**而且原作換地圖會覆寫自動存檔**(琉璃仙洞那份存檔就這樣沒了,現在的起點是洞口外的「琉璃仙境通道」,備份在 `game/Saves/exsave99.corridor.bak`)。加了拴繩。
4. **被圍毆 = 永久硬直**:160 隻疊上來後,主角 `obj+0x188` 永遠不歸零,普攻和放招全被原作擋掉,擊殺數卡住不動。加「霸體」:放招前清 `+0x188`,卡超過 1.2 秒也清一次(一場 42–62 次)。
5. **圖像和數值不能亂配**:弓手圖像 + 刀手數值這類組合,第 4 波直接閃退(沒有錯誤視窗)。只用照原作順序對得上的配對。
6. 原作 Lv1 素還真太脆:只加自動出手反而 5 秒就死,要一起調難度曲線。

## 限制 / 沒做到

- **Q 換戰友接招沒測**:存檔只有一位戰友;逆向看 Q 是「輪替上場的戰友」不是切換操作對象,要做「換人接招」得另外找切換主控的路(`gs+0x80fc` 決定操作 `gs+8` 還是 `gs+0xc`,沒試)。
- 換武器只確認數值有變;人物外觀 / 攻擊動作推測不變(沒並排對照)。
- 「召喚助戰」「絕招威力」兩個選項只確認寫入成功,效果沒量。
- 絕招都是原作的單體或小範圍招,**沒有真正的大範圍清場**;怪多了擊殺速度跟不上(160 隻時卡在每秒不到 1 隻)。要割草感得再做範圍傷害(原作絕招傷害函式 `0x43e140` 是腳本指令,還沒試直接呼叫)。
- 其他角色的招(例如 15 一字刀法)沒試在素還真身上放,可能缺動作;現在只給素還真自己的 7 招。
- 怪還是用推的(v0 的問題還在),沒有走路動畫;沒做碰撞,會推進樹裡。
- 霸體是硬清硬直,被打的受擊動畫會被切掉。
- 入口還是 F9;沒有做主選單按鈕、沒有做結算後重來(主角死了原作會跳「進度讀取」選單)。
- 存活時間樣本只有 2 次、主角不走位;手動走位的難度沒測(沒有真人玩過)。
- 自動存檔會被換地圖覆寫,`tools/load.sh` 每次先還原備份。
