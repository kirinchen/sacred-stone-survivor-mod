# 13 技能樹(升級 / 進化)、後期掉幀、WASD 走路

> 2026-11-23(Kirin 2026-11-23:3 選 1 要有技能成長、後期怪多會卡、移動改 WASD)。
> 遊戲 V2.85;位址只對這個版本。程式在 `mod/src/sssmod.c`(技能、WASD)和 `mod/src/rogue.c`(怪的上限、清特效)。

## 結論

- **技能成長照 Kirin 定案的規則做了**:每招 Lv 1 → Lv 5 靠 3 選 1 升;滿 Lv 5 後下一次 3 選 1 保證出「進化」,選了就換成同組下一階,同一格,等級回 Lv 1。
- **每次 3 選 1 至少 1 個技能選項**(學新招 / 升級 / 進化),有得選的話。
- **掉幀的原因不是怪的數量本身,是被圍毆時的特效物件**。場上怪上限 80 → 50、特效超過 60 個就清掉多的:同一個時間點從 44 fps 回到平均 59。
- **WASD 可以走**:按住往那個方向走、放開就停、可斜向。滑鼠點地板照舊能用。

## 技能成長

### 規則

| 選項 | 什麼時候出現 | 效果 |
|---|---|---|
| 學新絕招 | 技能格還有空、還有沒學的招 | 照原本的清單學下一招 |
| 升級:某招 Lv n → n+1 | 技能格裡有沒滿 Lv 5 的招(隨機挑一招)| 那一招 威力 +35%、冷卻 −8%(每級,以原始值算)|
| 進化:某招 Lv 5 → 下一階 | 有招滿 Lv 5、同組還有下一階 | 換成下一階的招,佔原本那一格,等級回 Lv 1 |

- 有招滿 Lv 5 → 下一次 3 選 1 **保證**有「進化」。
- 3 個選項裡沒有任何技能選項 → 隨機換掉一個,補上一個技能選項。
- 技能格上會顯示等級:`[1 龍氣劍 Lv3]`。
- 等級、進化都只算這一局;結束後這局學的招照舊忘掉。
- 只有威力和冷卻會變。範圍沒有動(招式表裡哪一欄是範圍還沒驗,見 [04](04-skill-list.md))。

## 後期掉幀

### 量到什麼

量法:log 每秒一行 `fps=… obj=… enemy=…`;把今晚所有紀錄照怪的數量、物件總數分組。

| 分組 | 結果 |
|---|---|
| 怪 0–90 隻 | 平均 53–57 fps,跟怪的數量幾乎無關 |
| 物件總數 ≤ 175 | 約 55 fps |
| 物件 200–300 | 約 50 fps |
| 物件 375 以上 | 約 40 fps |
| 物件 800 以上 | 約 34 fps |

後期(7:55、主角被 57 隻怪同時打)把場上 291 個物件分類:

| 物件 | 數量 |
|---|---|
| 特效(vtable `0x4ab608`)| 183:type 6015 有 111 個、1051 有 45 個、1010 有 15 個 |
| 怪和主角 | 76 |
| 其他(class `0x400000`,地圖上的東西)| 21 |
| 掉落物 | 3 |

這時 44 fps。type 6015 / 1051 是什麼特效沒有逐一確認(位置都在主角身邊、離地 54–60,推測是受擊 / 命中的特效)。

### 改了什麼

- **場上怪的上限 80 → 50**(頭目戰 45 → 35)。少而強:小怪攻擊 ×1.3,命沒動。
- **特效超過 60 個就把多的刪掉**(每 150 ms 數一次 type 6015 / 1051,刪物件用 `0x44ec10`)。刪的時候出過例外就自動關掉這個功能。
- **地上的掉落物 12 個以上就不再多生丹藥**。掉落物本身不是掉幀的原因(上表只有 3 個),這條只是防堆積。

## WASD 走路

- 一局中 W / A / S / D 不給原作,模組自己記哪幾個鍵按著。
- 每 120 ms 用原作的「走到」`0x445a80` 往那個方向 90 px(上下 60 px)外走;全放開時叫一次「走到自己腳下」= 停。
- 斜向 = 兩個鍵一起按。相反的兩個鍵一起按算沒按。
- 視窗失去焦點、3 選 1 選單開著時把按鍵狀態清掉。
- 滑鼠點地板(原作的)照舊。

- 指令直接設按鍵狀態:D 2 秒 x 640 → 878;W + A 2 秒往左上;放開後位置不再變。

## 2026-11-24 修:走進出口就輸、WASD 一直轉 / 卡住(Kirin 實玩回報)

> 上面「真人玩會中途被判失敗(沒解)」和「WASD 走路」兩節,以這節為準。

### 走進出口就輸(已修)

- **原因**:主角自己走進出口,原作走的是第三支 `0x419a40(scene, 出口索引)`,它直接寫排程欄位,不經過模組已經擋掉的 `0x419980` / `0x4198a0`。腳本代玩只在地圖中央繞,所以一直沒踩到。Kirin 那幾局「選完 3 選 1 後約 10 秒被判失敗」就是這個(log `lead lost` 顯示主角人在另一張圖的 stage 物件上、`blocked_exits=0`)。
- **修法**:`0x419a40` 也掛上(開頭位元組跟另外兩支一樣)。
- **踩到的坑**:只擋 `0x419a40` 的話,呼叫它的 `0x43e8c0` 接著會把主角和夥伴的 `obj+0x7c` 設上 `0x40000000`(換圖中、不准動)→ 兩個人凍在原地(實測)。擋掉之後下一幀把這個旗標清掉。
- **實測**(1 次):主角用 WASD 走到出口(16, 223),log `blocked_exits=3`,這局沒中斷,之後還能走(3 秒走了約 500 px)。

### WASD 一直轉 / 卡住(已改)

- **原因**:原本每 120 ms 重下一次「走到」。Kirin 用 WASD 的兩局,主角 84%、99% 的時間卡在動作鎖(`obj+0x188`)裡(log `v1 end` 的 `locked=`;腳本代玩是 15–22%)。另外每一刀的揮砍動作都會打斷走路。
- **改法**:
  - 方向變了才下指令,目標放在那個方向 240 px 外(上下 160 px),先挪到最近的可走格;按住時每 500 ms 補一次
  - 按著 WASD 時普攻只結算、不播揮砍動作
  - 按著方向鍵卻被動作鎖住超過 0.35 秒 → 解開、馬上再走
- **實測**(指令設按鍵狀態,1 次,主角開無敵):46 秒走了 3524 px,走路 44%、被鎖 11%;放開後位置不再變。
- **沒驗**:真人鍵盤的手感;不開無敵、被圍住時走不走得出來;放招的動作會不會因為「解鎖」被切掉。

## 2026-11-24 修:按 W 就一直放「八卦迷蹤步」、W / S 方向相反(Kirin 實玩回報)

- **原因 1:W/A/S/D 是原作的熱鍵「八卦迷蹤步」**([01](01-feasibility.md) 的熱鍵表就有,做 WASD 時漏看)。原作在玩家輸入處理 `0x449080` 裡的 `0x44920c` 直接看鍵盤掃描碼位元表 `0x4c78a0`(W = bit 17、A / S = bit 30 / 31、D = `0x4c78a4` 的 bit 0),有按就叫 `0x4474e0(obj, x, y)`:目標 = 現在位置往那個方向 160 px,指令 `obj+0x134 = 9`。
  - 不走視窗訊息 → 模組攔 `WM_KEYDOWN` 攔不到。
  - `0x4474e0` 只檢查「戰鬥地圖、能動、`obj+0x1f4` ≤ 0(看起來是冷卻)」,**這一段沒有扣內力**;指令 9 實際執行的部分沒讀(冷卻多長、有沒有無敵不知道)。
  - 按住就會冷卻一好再衝一次 → Kirin 看到的「瘋狂一直轉、不能控制」。
- **修法**:倖存者模式開著時把 `0x44920c` 的 `mov eax,[0x4c78a0]` 換成 `jmp 0x44922b`(跳過三個判斷),結束換回來。平常玩原作不受影響。log `wasd patch: original W/A/S/D dodge hotkey off / back on`。
- **原因 2:W / S 做反了**。物件座標的 y 往上是正的(實測:點畫面上方,主角 y 511 → 590),原本 W 寫成 y 減少 = 畫面上往下走。已改。
- **實測**(送 `WM_KEYDOWN` / `WM_KEYUP` 訊息,1 次):W y 511 → 879、D x 672 → 1087、S y 840 → 384、A x 1104 → 770;放開後位置不再變。
- **沒驗到**:真的鍵盤輸入。腳本沒辦法把遊戲視窗切到前景(Windows 擋),試了 2 次都沒送進去。「原作那招不會再觸發」目前只有靜態依據(那段程式被跳過)加上 log 顯示有改成功。
- 方向鍵沒有改用:原作同樣直接讀上下左右(`0x4282a1` 一帶讀掃描碼表 `0x4c78b9` / `0x4c78ba`),用途沒查。
- 之後可以做:把這招另外綁一顆鍵(例如空白鍵往目前方向衝一次)當閃避。

## 2026-11-24 改:點到怪不再站定打(Kirin:「普攻會停下來打」)

- 模組的自動普攻(`survatk 1`)本來就是邊走邊結算,不會讓主角停([08](08-move-attack-cd-slots.md))。會停的是原作的普攻指令 `0x447230`(玩家點到怪、按住左鍵掃過怪時叫):主角走到目標旁站定揮刀。
- **改法**:掛在 `0x447230` 開頭。倖存者模式、對象是主角、有目標時:玩家按著左鍵 → 改成「走到點的位置」(`0x445a80`);不是按著左鍵叫的 → 不做。目標 = 0(Ctrl 原地攻擊)和其他角色照舊。
