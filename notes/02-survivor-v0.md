# 02 倖存者模式 v0(熱鍵版)

> 2026-11-09。Kirin:先做熱鍵、不開卡。**v1(自動放招 + 升級選單,波次 / 上限數字有改)見 [03-survivor-v1.md](03-survivor-v1.md);怪改用原作走路見 [05-enemy-walk.md](05-enemy-walk.md)。**程式在 `mod/src/sssmod.c`「倖存者模式 v0」段。

## 怎麼玩

1. 用模組開遊戲(`tools/relaunch.sh`,或把 `mod/build/dsound.dll` 放進 `game/` 再開 `WUJIN.exe -window`)
2. 照劇情走到**戰鬥地圖**(野外 / 地城,例如琉璃仙洞;城鎮不開戰鬥)
3. 按 **F9** 開始;再按一次 F9 提前結束;結算畫面再按 F9 收起

## 規則

| 項目 | v0 |
|---|---|
| 波次 | 第 w 波生 6+3w 隻;間隔 8 秒,每波減 0.5 秒,最快 3 秒 |
| 生在哪 | 主角外圍 100–170 px 的環上 |
| 怪物種類 | 開始時場上看到的敵人 + 黃刀手(2077/13);蝙蝠幾乎不打人 |
| 上限 | 場上 160 隻,滿了就等 |
| 追擊 | 每 50 ms 把離主角 > 50 px 的敵人往主角推 2 px(約 40 px/s) |
| 結算 | 主角命歸零、換地圖、或按 F9 → 顯示存活秒數 / 擊殺數 |
| 擊殺數 | 開始時敵人數 + 已生數 − 現存敵人數(隊友殺的也算) |

可調指令(寫進 `game/sss_cmd.txt`):`surv`(= F9)、`survr MIN MAX`(生成半徑)、`survpull N`(追擊速度,0 = 關)、`post M W L`(走訊息佇列送鍵,測熱鍵用)。

## 實測(琉璃仙洞,不操作主角)

- 沒有追擊時:怪停在索敵範圍外不過來,主角滿血站 4 分鐘;主角一走進怪群幾秒就死 → **原作怪物索敵範圍很小**
- 加推力後:16 秒第 3 波被圍死,擊殺 11;FPS 全程 60

## 已知問題 / 下一步

- 追擊是直接改座標,怪用「滑」的,沒有走路動畫;要自然得找怪物 AI 的索敵範圍(之後逆向)
- 沒有升級 / 經驗選擇;沒有難度曲線調整(目前不操作 16 秒就死,手動玩的難度還沒試)
- 入口只有熱鍵;選單按鈕、直接傳送到戰鬥地圖都還沒做(還是要先跑劇情)
- 推力可能把怪推進牆裡(沒做碰撞)
